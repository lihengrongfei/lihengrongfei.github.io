Hybrid Vision Drone Detection

A multimodal detection pipeline that combines conventional RGB images with event-camera signals to improve drone detection in difficult scenes.

Apr — Jul 2026Python · YOLO11 · Event Vision
View on GitHub ↗

Overview

RGB and event streams are processed by complementary detectors and combined through late fusion. The project also explores event reconstruction, tracking, evaluation tooling, and a lightweight interface for reviewing detections.

Highlights

  • Synchronized RGB and event processing
  • Verifier-based late fusion
  • Evaluation and browser-based review tools

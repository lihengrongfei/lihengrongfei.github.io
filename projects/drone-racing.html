Overview

The project generates smooth references through racing gates and follows them with model predictive contouring control. The controller balances progress, tracking accuracy, and input limits while supporting online replanning.

Highlights

  • Spline-based reference generation
  • Model predictive contouring control
  • Simulation and real Crazyflie tests
